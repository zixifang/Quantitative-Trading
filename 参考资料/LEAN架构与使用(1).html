02

一个时间片里发生什么

回测把历史走完；实盘则停在“等下一块数据”。第 3 步到第 7 步不断重复。

第 7 步之后，只要算法时间还没到结束日，就回到第 3 步取下一块切片。

一笔订单怎么走

策略MarketOrder / SetHoldings只生成订单请求
Security购买力预检保证金不够会直接拒绝
ITransactionHandlerBacktestingTransactionHandler回测与模拟盘走本地撮合
成交FillModel 按行情假设成交费用和滑点来自 BrokerageModel
OrderEvent状态回到算法Submitted、Filled、Canceled
Portfolio现金与持仓更新然后才会进入 OnOrderEvent

03

策略的两种写法

两条路都继承 QCAlgorithm，最后都把订单送进同一个 TransactionHandler。Python 用 snake_case；C# 用同名的 PascalCase，文件是 Main.cs。

01

选股

Universe Selection。决定这一期交易哪些标的，变动通过 OnSecuritiesChanged 通知。

→ 证券集合
02

Alpha

对每个标的给出 Insight：涨、跌或平，外加有效期。

→ Insight
03

组合

Portfolio Construction 把 Insight 收成目标权重。

→ PortfolioTarget
04

风控

Risk Management 可以削减、清空目标，不能凭空加仓。

→ 调整后的目标
05

执行

Execution 比较目标和当前持仓，发出订单。

→ Order
经典 · main.py规则全写在 OnData
from AlgorithmImports import *

class SmaCross(QCAlgorithm):
    def initialize(self):
        self.set_start_date(2018, 1, 1)
        self.set_cash(100_000)
        self.symbol = self.add_equity("SPY", Resolution.DAILY).symbol
        self.fast = self.sma(self.symbol, 10, Resolution.DAILY)
        self.slow = self.sma(self.symbol, 30, Resolution.DAILY)

    def on_data(self, data: Slice):
        if not self.fast.is_ready or not self.slow.is_ready:
            return
        holding = self.portfolio[self.symbol]
        if not holding.invested and self.fast.current.value > self.slow.current.value:
            self.set_holdings(self.symbol, 1)
        elif holding.invested and self.fast.current.value < self.slow.current.value:
            self.liquidate(self.symbol)

from AlgorithmImports import *

class FrameworkDemo(QCAlgorithm):
    def initialize(self):
        self.set_start_date(2018, 1, 1)
        self.set_cash(100_000)
        self.universe_settings.resolution = Resolution.DAILY
        symbol = Symbol.create("SPY", SecurityType.EQUITY, Market.USA)
        self.set_universe_selection(ManualUniverseSelectionModel([symbol]))
        self.add_alpha(EmaCrossAlphaModel(10, 30, Resolution.DAILY))
        self.set_portfolio_construction(EqualWeightingPortfolioConstructionModel())
        self.add_risk_management(MaximumDrawdownPercentPerSecurity(0.05))
        self.set_execution(ImmediateExecutionModel())

手续费、滑点和保证金不写在下单那一行。它们来自 set_brokerage_model(...) 装上的 IBrokerageModel。这只改规则，不会登录券商。

04

回测、模拟、实盘换的是哪几块

策略类保持不动。live-paper 的成交仍用回测那只 TransactionHandler，在本地模拟；真仓才换成 BrokerageTransactionHandler。行情队列和下单券商可以拆开，例如 live-interactive-iqfeed 用盈透下单、IQFeed 供数。

插槽回测 backtesting模拟盘 live-paper实盘 live-interactive
SetupBacktestingSetupHandlerBrokerageSetupHandlerBrokerageSetupHandler
DataFeedFileSystemDataFeedLiveTradingDataFeedLiveTradingDataFeed
DataQueue本地文件LiveDataQueueInteractiveBrokersBrokerage
TransactionBacktestingTransactionHandlerBacktestingTransactionHandlerBrokerageTransactionHandler
ResultBacktestingResultHandlerLiveTradingResultHandlerLiveTradingResultHandler
RealTimeBacktestingRealTimeHandlerLiveTradingRealTimeHandlerLiveTradingRealTimeHandler
Brokerage无连接，FillModel 成交PaperBrokerageInteractiveBrokersBrokerage
HistorySubscriptionDataReaderHistoryProvider环境里不覆盖BrokerageHistoryProvider，再加本地文件

时钟也一起换：回测的 RealTimeHandler 把 schedule.on 对齐到算法时间；实盘按墙钟触发。OnData 拿到的仍是 Slice。

05

从零跑起来

1

安装 CLI，并先启动 Docker。QuantConnect 文档要求使用 CLI 的组织处于付费层级。引擎源码是 Apache-2.0，也可以不装 CLI，直接跑 Launcher。
pip install lean

2

在空目录登录并生成工作区。此步会准备 LEAN 配置。
lean login
lean init

3

生成策略目录：main.py、research.ipynb、config.json。
lean project-create --language python "SmaCross"

4

写第 03 节里的算法。本地行情放在工作区 data/，股票日线路径形如 data/equity/usa/daily/spy.zip。随机数据可用 lean data generate --help 查看参数。

5

研究用笔记本，回测在 Docker 里跑，结果进 SmaCross/backtests/<时间戳>/。
lean research "SmaCross"
lean backtest "SmaCross"

6

云端回测会先同步再跑。本机实盘用向导选择券商和行情源，模拟盘选 Paper。
lean cloud backtest "SmaCross" --open --push
lean live deploy "SmaCross"

工作区lean.json 管全局，config.json 管单个策略
组织工作区/
├── lean.json                 # 数据目录、组织
├── data/
│   └── equity/usa/daily/spy.zip
└── SmaCross/
    ├── main.py               # 或 Main.cs
    ├── research.ipynb
    ├── config.json           # 语言、参数
    ├── backtests/<时间戳>/
    └── live/<时间戳>/

不用 CLI 时：克隆 github.com/QuantConnect/Lean，编译并运行 Launcher。把 Launcher/config.json 的 environment 设为 backtesting，数据放进仓库的 Data 目录。
